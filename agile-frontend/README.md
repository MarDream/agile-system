# agile-frontend

前端工程基于 Vue 3、TypeScript、Vite、Pinia、Element Plus。

## 启动

```bash
npm install --legacy-peer-deps --no-package-lock
npm run dev
```

## 常用脚本

```bash
npm run build
npm run test:login-flow
npm run serve:dist
npm run test:full-chain
npm run test:e2e-login
```

## 目录

```text
agile-frontend
├── public
├── scripts
├── src
├── types
├── package.json
└── vite.config.ts
```
